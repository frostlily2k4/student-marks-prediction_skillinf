# Student Marks Prediction

## Project Overview
Student Marks Prediction is a beginner-friendly machine learning project that estimates student marks using study hours, attendance percentage, and previous assessment marks.

## Objective
To build and evaluate a regression model that predicts academic marks from sample student data.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn

## Machine Learning Algorithm
Linear Regression

## Dataset Features
- Study Hours
- Attendance Percentage
- Previous Marks
- Final Marks (target variable)

## Methodology
1. Prepare and load the sample dataset.
2. Separate input features and target values.
3. Split the data into training and testing sets.
4. Train a Linear Regression model.
5. Generate predictions on test data.
6. Evaluate the model using MAE, RMSE, and R².
7. Display predicted and actual marks.

## How to Run
Install the dependencies:

```bash
python -m pip install pandas numpy scikit-learn
```

Run the program:

```bash
python train_model.py
```

## Important Disclaimer
This project uses illustrative sample data for educational purposes. Predictions are estimates, not guarantees of actual academic results. Real academic performance depends on many additional factors.
